x402 setup check

Checks your project for x402 SDK versions with publicly reported flaws, and for settings that turn the default spending limit off. Free.

The check runs inside this page. Your files are not uploaded, and the page is not allowed to make network requests.

Drop your project folder or lockfile here
package-lock.json, pnpm-lock.yaml, yarn.lock, bun.lock, requirements.txt, poetry.lock, uv.lock, Pipfile.lock, pyproject.toml, go.mod, or .js/.ts/.py source

What it checks

  • Out-of-date x402 packages with flaws reported in October 2026, including transitive ones in your lockfile. For example, @x402/fetch and @x402/axios before 2.23.0 had no default spending limit, and @x402/core is fixed in 2.27.0.
  • Spending limits switched off in code: spendControls: false, maxAmountPerPayment: false, allowedAssets: true and custom payment pickers, plus the Python equivalents.
  • Legacy x402 v1 packages, which did not receive the 2026 fixes.
